# スカイラインテクノロジーズ 企業サイト（練習用）

## 概要

クラウド・AI・業務システム開発で企業のDXを支援するソフトウェア会社「スカイラインテクノロジーズ」の企業サイトです。
HTML・CSS・JavaScript を `index.html` 1ファイルにまとめた、1ページ構成のサイトです。

### ページ構成

| セクション | 内容 |
| --- | --- |
| トップ（ヒーロー） | キャッチコピー「テクノロジーで、ビジネスの空を広げる。」 |
| 私たちについて | 企業理念・ミッション |
| サービス | クラウド開発・移行 / AI・データ活用 / 受託システム開発 |
| 自社プロダクト | SkyBoard |
| 導入実績 | 配送管理システムのクラウド化 ほか |
| お知らせ | 最新ニュース |
| 会社概要 | 会社情報 |
| お問い合わせ | お問い合わせフォーム |

### ファイル構成

```
company-site練習用/
├── index.html   # サイト本体（HTML・CSS・JavaScript）
└── README.md    # このファイル
```

## ブラウザで index.html を開く手順

ビルドやサーバーの準備は不要です。次のいずれかの方法で開けます。

### 方法1：ダブルクリックで開く

1. エクスプローラーで `company-site練習用` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザ（Chrome、Edge など）でサイトが表示されます。

### 方法2：ブラウザにドラッグ＆ドロップする

1. ブラウザを起動します。
2. `index.html` をブラウザのウィンドウにドラッグ＆ドロップします。

### 方法3：コマンドで開く（PowerShell）

```powershell
cd "C:\Users\user\Desktop\company-site練習用"
start index.html
```

> **補足：** フォント（Noto Sans JP / Inter）は Google Fonts から読み込んでいます。
> インターネットに接続していない場合は、別のフォントで表示されます。
